# Invalidated exploratory pilot

These 29 completed GPT-6 Luna runs predate the corrected isolation control. They include a balanced first pass and partial repetitions started before the user selected an 18-run preliminary report. Subsequent repetitions were stopped. They are not part of the primary benchmark.

The personal-skill disable list used directories instead of SKILL.md files and omitted symlinked skill folders. Background skill metadata may therefore have influenced outcomes. No enabled-catalogue preflight was performed. The replacement comparison verifies exactly the intended enabled skills before any model run.

The pilot's first 18 runs used 5.1% more total tokens in the condensed condition, unlike the controlled rerun. A further condensed review (`review-condensed-2`) found only the unsafe slice bug, missing the empty-input panic and truncating cast. This is a useful reliability warning, even though the uncontrolled sample cannot establish comparative performance. All pilot records are retained here to avoid selectively reporting favourable outcomes.

No aggregate effectiveness or token-saving claim should use this directory. See ../2026-10-25-luna-isolated for the primary evidence.
